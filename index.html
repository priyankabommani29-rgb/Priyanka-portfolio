Hand Gesture Volume Control

Traditional computer interaction relies on physical input devices, which can be limiting in hands-free or accessibility-focused scenarios. This project uses OpenCV and MediaPipe to recognize real-time hand gestures and translate them into desktop actions such as cursor movement, clicks, scrolling, and volume control. It demonstrates how computer vision can create a more intuitive and touchless user experience.
